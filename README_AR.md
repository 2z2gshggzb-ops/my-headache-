# يومي v1.8.21 — خط اتجاه البوتوكس ونطاق الجلسات

**مبني على v1.8.20**، ويتضمن جميع إصلاحات تنبيهات التحليل الحمراء وتنسيق استجابة الأدوية في الإصدارات السابقة.

## التغييرات

- صفحة البوتوكس المستقلة: رسم **اتجاه أيام الصداع/الشقيقة خلال فترات 30 يومًا**، مع خط بلون التطبيق يربط النقاط المتتابعة التي تتوفر لها بيانات كافية.
- العلامات **الحمراء** هي مواعيد جلسات البوتوكس المسجلة، وليست قيمًا للصداع.
- توجد خطوط **متقطعة** إذا كان أحد الطرفين عددًا جزئيًا مسجلًا أو فصلت جلسة جديدة بين فترتين بعدد قليل من الأيام. لا يرسم خطًا عبر فترة لا تحتوي أي سجلات تسمح بحساب عدد الأيام؛ ولا تُعامل فجوات البيانات على أنها صفر صداع.
- اختيار النطاق أعلى الرسم: **آخر 12 شهرًا (افتراضي)** أو **آخر جرعة / آخر جرعتين / آخر 3، 4... جرعات** حسب الجلسات الفعلية المسجلة، أو **كل الجلسات**.
- يتذكر النطاق المختار عند التنقل بين صفحات التطبيق في نفس جلسة التشغيل، وتظهر الفترات الطويلة مع سحب أفقي.
- بقية التطبيق، بما في ذلك مواعيد البوتوكس الثلاثة أشهر تقويميًا، ومهلة استجابة الأدوية 150 دقيقة، وتحليلات الصداع والماء، دون تغيير.

## التثبيت

1. ارفع الملفات الثلاثة `app.js`, `styles.css`, `sw.js` إلى المستودع نفسه واستبدل الإصدارات السابقة.
2. انتظر نشر GitHub Pages، ثم أعد فتح تطبيق «يومي» على آيفون.
3. لا تستورد JSON جديدًا. نسخة احتياطية خارج التطبيق دائمًا مستحسنة قبل أي تحديث.

## ملاحظات

- عندما لا توجد جلسات كافية، لن تظهر اختيارات 2 و3 و4 جرعات حتى تسجّلها.
- المعلومات وصفية وليست تقييمًا سببيًا لفعالية البوتوكس.
