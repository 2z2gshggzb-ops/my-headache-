تحديث إصلاح شاشة النوم المستورد من RingConn - يومي

مهم: هذا تحديث صغير فوق نسخة RingConn Sync التي رفعتها سابقًا. لا يخص تذكيرات الماء.

طريقة التركيب:
1. تأكد أن لديك نسخة احتياطية JSON من سجلات يومي.
2. ارفع فقط app.js و sw.js إلى جذر مستودع GitHub mzaitooni/yawmi مع استبدال الملفين الحاليين.
3. لا تحذف تطبيق يومي ولا تمسح بيانات المتصفح.
4. بعد تحديث GitHub Pages، اغلق يومي من مبدّل التطبيقات وافتحه مجددًا.
5. افتح السجل المستورد بتاريخ 30 أكتوبر. ستظهر "تفاصيل نوم Apple Health" وفيها النوم الفعلي 8:50 والفترة بين وقتي النوم والصحيان 9:05 ومراحل النوم.
6. زر "إغلاق" لا يغير السجل. زر "تحويل إلى تسجيل يدوي" يطلب تأكيدًا قبل السماح بتعديل الوقتين وتحويل السجل إلى يدوي، وبعد تحويله لن يعود متزامنًا.

لا تضغط تحويل إلى يدوي لاختبار العرض. فقط افتح التفاصيل وصورها للتأكد.
لم يتم تعديل أي سجل شخصي في هذا التحديث؛ التعديل فقط في كود الواجهة.
