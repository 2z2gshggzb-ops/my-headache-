تحديث شعار تطبيق يومي عبر GitHub Pages

المستودع: daily-health

1. فك ضغط هذا الملف على جهازك.
2. افتح GitHub > مستودع daily-health > Add file > Upload files.
3. ارفع ملفات PNG الثلاثة الموجودة هنا إلى جذر المستودع (نفس مجلد index.html).
4. وافق على استبدال الملفات الموجودة باسم icon-192.png وicon-512.png ثم اضغط Commit changes.
5. بعد نشر GitHub Pages افتح التطبيق في Safari. لإظهار أيقونة جديدة على شاشة iPhone، احذف اختصار التطبيق القديم ثم اختر مشاركة > إضافة إلى الشاشة الرئيسية.

مهم: لا ترفع ملف ZIP ذاته إلى GitHub؛ ارفع الصور الموجودة بداخله.
لن تحتاج تعديل HTML إذا كانت الأيقونات الحالية مربوطة بأسماء icon-192.png وicon-512.png.
إذا كانت تستخدم أسماء أخرى، أو كانت الأيقونات مخزنة في Cache الخاص بـ service worker، قد يلزم تعديل index.html أو manifest أو service-worker.
